# تقرير الاختبار النهائي

تاريخ الاختبار: 11 أكتوبر 2026. استُخدم متصفح Chromium مع خادم ملفات ساكن، إضافة إلى اختبارات JavaScript مباشرة لوظائف الترحيل والتحقق.

## اختبارات متصفح ناجحة

| الحالة | النتيجة |
|---|---|
| المتن العربي المشكول | ظهر عنوانًا مستقلًا فوق الرسم ولم يصبح عقدة أو وصلة |
| النبي ﷺ مع طريق منفصل | بقي النبي وحده في أعلى طبقة، وبدأ الطريق المنفصل في طبقة أدنى بلا وصلة مخترعة |
| تفرع ثم التقاء ثم تفرع | المقطع المشترك أخضر، والفرعان بلونين ثابتين، ثم عاد المقطع الملتقي إلى اللون المشترك، ثم اختلف لونا التفرع الثاني |
| تلوين الأسانيد | ظهرت الوصلة المشتركة بخطين متوازيين بلونين مختلفين |
| تمييز طريق | برز المسار كاملًا وخفتت العناصر الأخرى من غير تغيير البيانات |
| فتح تفاصيل راوٍ | لم تتغير أي إحداثيات في الرسم |
| مستوى يدوي | انتقلت العقدة واللاحقات إلى مستوى أدنى مع بقاء النبي في الأعلى |
| 30 إسنادًا وأسماء طويلة | ظهرت 30 سجلاً، ولم يُكتشف أي تداخل بين صناديق الرواة |
| الحفظ وإعادة الفتح | عادت الأسانيد الثلاثون والمتن بعد إعادة تحميل الصفحة |
| الاستمرارية عبر إغلاق المتصفح | أُغلق Chromium كليًا ثم أعيد فتحه بالملف المحلي نفسه، فعاد آخر مشروع نشط والباحث والمتن والطريقان |
| حالة الحفظ | ظهرت «جارٍ الحفظ» أثناء العمل و«تم الحفظ» بعد نجاح IndexedDB |
| فشل حفظ متعمد | أُغلق اتصال IndexedDB قبل الحفظ، فظهرت «تعذّر الحفظ» ولم يُعرض نجاح كاذب |
| نسخة JSON كاملة | صُدرت النسخة، ثم استوردت كمشروع جديد، وبقي الباحث وملاحظاته والمتن والطريقان والمصادر |
| مشروع من الإصدار السابق | فُتح مشروع إصدار 4 بلا حقول الباحث، وظهرت الحقول الجديدة فارغة من غير تعطل أو فقد للرسم |
| اسمان متطابقان بهويتين مختلفتين | بقيا أربع هويات مستقلة عبر طريقين عند إيقاف الدمج التلقائي |
| دورة متعمدة | رُفضت وعاد عدد الطرق والهويات والوصلات إلى حالته السابقة |
| إدخال فارغ أو ناقص | رُفض برسالة عربية ولم تتغير البيانات |
| حذف طريق له وصلة مشتركة | بقيت الوصلة ما دام الطريق الآخر يستخدمها |
| إنشاء نسخة من مشروع | أُنشئ مشروع مستقل باسم ينتهي بـ«نسخة» |
| نص شبيه بـHTML ضار | لم يُنشأ عنصر صورة ولم يظهر مربع تنفيذ؛ بقي النص بيانات فقط |
| حاشية طويلة مشكولة | ظهرت في لوحة الحواشي، ولم يسجل المتصفح خطأ عند إنشاء SVG |
| خيارات التصدير | ظهرت مفاتيح مستقلة للعنوان والمتن والرسم والمصادر والحواشي والمفتاح |
| SVG باسم الباحث وبدونه | فُحص الملفان من القرص؛ ظهر سطر «دراسة وإعداد» عند التفعيل وغاب تمامًا عند الإلغاء |
| PNG باسم الباحث وبدونه | نُزّل الملفان وفُحص توقيع PNG والحجم، ثم راجعت صورة النسخة المنسوبة بصريًا |
| قياس أسماء الرواة | بقي الاسم العربي المعتاد في سطر واحد، والتف الاسم الاستثنائي الطويل عند حدود الكلمات فقط، وبقي النص داخل صندوقه |
| التخطيط المحسّن | لم تتداخل صناديق الرسم المركب ذي خمسة طرق، وتقاربت المكونات المنفصلة من دون فراغ أفقي مفرط |
| PNG عالي الدقة | صُدرت صورة فعلية بدقة رسم 3× لرسم مركب، وشملت الرسم كاملًا بهوامش محكمة وأسماء عربية مقروءة |
| تقرير PDF العربي | فُتح تقرير فعلي يضم المتن واسم الباحث وخمسة أسانيد بترتيبها ومصدرًا وحاشيتين وملاحظات الباحث |
| تقرير A4 أفقي | أُنشئ PDF فعلي من Chromium من ثلاث صفحات A4 أفقية؛ اجتمع العنوان والمتن واسم الباحث والرسم في الصفحة الأولى من دون صفحة عنوان فارغة |
| قائمة الأسانيد الاختيارية | ظهرت خمسة أسانيد عند التفعيل، واختفت القائمة عند الإلغاء مع بقاء المصدرين في قسم المصادر |
| صيغ أداء خاصة بالطريق | حُفظت «حدثنا» و«عن» بشكل مستقل لطريقين يشتركان في الوصلة نفسها، وبقيتا بعد إعادة التحميل وظهرتا في الرسم وSVG وPNG وPDF |
| أكثر من مصدر | ظهر «صحيح البخاري» و«مسند أحمد» في التقرير من غير تقسيم مدخل المصدر نفسه بين صفحتين |
| إلغاء التحديد | نجح بالنقر الثاني، والنقر على الخلفية، وEscape، وزر × |
| استقلال فتح بطاقة الطريق | فتح البطاقة وإغلاقها لم يغيّر التمييز؛ زر «تمييز الطريق» وحده غيّره |
| السحب اليدوي | عند تكبير غير افتراضي تحركت العقدة بانسياب، وتبعتها الوصلات أثناء السحب، وانتهى السحب بعد إفلات المؤشر خارج الرسم، ثم عاد الموضع نفسه بعد الحفظ وإعادة التحميل |
| سباق حفظ متعمد | طُلب حفظ نسختين متتاليتين سريعًا؛ بقي العنوان الأحدث في IndexedDB ولم تستبدله اللقطة الأقدم |

## اختبارات JavaScript ناجحة

- ترحيل مشروع الإصدار الأول ذي حقل الأسانيد النصي إلى الإصدار السادس.
- بقاء الأسماء المعروضة المتطابقة هويات داخلية مستقلة.
- رفض دورة في ملف مستورد.
- رفض إسناد مستورد يحتوي راوياً واحدًا فقط.
- إبقاء النص غير الموثوق نصًا خامًا حتى تعرضه الواجهة بالهروب الآمن أو `textContent`.
- فحص الصياغة الكامل لملف `app.js` بمحرك Node.js.
- حفظ حقلي «دراسة وإعداد» و«ملاحظات الباحث» خلال التنقية والترحيل.
- حفظ مصفوفة صيغ الأداء لكل إسناد على حدة وترحيل المشاريع القديمة إلى مصفوفة فارغة من غير تغيير البنية.
- فحص أن طابور الحفظ متسلسل وأن الحالة الناجحة لا تظهر إلا للمراجعة الأحدث.
- فحص أن قياسات الصناديق تعتمد عرض النص الفعلي بخط Amiri، وأن المواضع اليدوية المحفوظة لا يعيد التخطيط الكتابة فوقها.

## ملفات التصدير التي فُحصت فعليًا

- `with-attribution.svg` و`without-attribution.svg`: بنية SVG ونص الإسناد والفرق في الإسناد البحثي.
- `with-attribution.png` و`without-attribution.png`: توقيع PNG وحجم غير صفري؛ روجعت النسخة المنسوبة بصريًا.
- `project-backup.json`: أعيد استيراده فعليًا عبر منتقي الملفات.
- `complex-diagram.svg` و`complex-diagram.png`: روجع الرسم المركب فعليًا للتأكد من اكتماله ووضوح الأسماء وعدم وجود قص أو فراغ مفرط.
- أُعيد إنشاء `research-report.pdf` بعد التحسين في ثلاث صفحات A4 أفقية، ورُسمت الصفحات الثلاث إلى صور وفُحصت بصريًا من دون صفحة فارغة أو قص.

لم يُنفّذ حذف مشروع حقيقي في ملف المستخدم أثناء الاختبار النهائي؛ فُحص مسار التأكيد والحذف في المصدر، بينما اختُبر إنشاء مشروع وإعادة تسميته ضمن مسار نافذة الاسم الآلي.

## ملاحظات الدقة

- لا تُنشأ وصلة إلا من زوج متجاور داخل إسناد محفوظ.
- الرسم مشتق من سجلات `chains` ولا يستبدلها.
- إزالة طريق تنظف بيانات الوصلات غير المستخدمة فقط.
- الاستيراد محدود الحجم ويُعاد بناؤه في كائنات جديدة، مع إعادة تعيين المعرّفات غير الآمنة ورفض الدورات والسجلات المشوهة.
