# مشجّرات الأسانيد — مكتبة العرض العامة

هذا المجلد موقع ثابت مستقل للعرض فقط. لا يتصل بالمحرر، ولا يستخدم IndexedDB، ولا يرفع البيانات إلى أي خدمة.

## الرفع اليدوي

1. فك ضغط الملف إن كنت تستخدم نسخة ZIP.
2. ارفع مجلد `hadith-tree` كاملًا إلى جذر مستودع موقعك، بجوار `isnad` و`tools.html`.
3. لا تغيّر أسماء الملفات الداخلية أو مجلد `assets`.
4. بعد نشر GitHub Pages افتح: `https://almutawakkil.github.io/hadith-tree/`.

## إضافة مشروع منشور

1. صدّر المشروع من محرر الأسانيد بصيغة JSON وراجعه علميًا وخصوصيًا.
2. أعط الملف اسمًا بسيطًا بالإنجليزية، مثل `actions-by-intentions.json`، وضعه داخل `hadith-tree/data/`.
3. افتح `hadith-tree/data/index.json` وأضف عنصرًا داخل `projects`:

```json
{
  "id": "actions-by-intentions",
  "title": "حديث «إنما الأعمال بالنيات»",
  "description": "وصف موجز اختياري.",
  "file": "actions-by-intentions.json",
  "routeCount": 12
}
```

- يجب أن يكون `id` فريدًا، بحروف لاتينية أو أرقام أو `_` أو `-` فقط.
- `routeCount` و`description` اختياريان. اكتب العدد فقط بعد التحقق منه.
- لا يلزم تعديل أي ملف JavaScript.

## إضافة الرابط إلى tools.html بنفسك

يوجد المقطع الجاهز في `tools-link-snippet.html`. الصقه في الموضع المناسب داخل قائمة الأدوات في صفحتك الحالية، وعدّل الغلاف المحيط فقط ليتوافق مع بنية الصفحة.

## الاختبار بعد النشر

1. افتح صفحة المكتبة وتأكد من ظهور البطاقة الجديدة.
2. افتح المشجّر وتحقق من جميع الطرق والأسماء والمراجع.
3. جرّب التكبير والتصغير والسحب وتمييز راوٍ ونهاية طريق.
4. جرّب تنزيل SVG وPNG.
5. افتح تقرير PDF واختر «حفظ كملف PDF» من نافذة الطباعة.
6. اختبر الصفحة على هاتف أو عبر وضع الهاتف في أدوات المطور.

## ملاحظة PDF

زر PDF يفتح تقريرًا نصيًا منظمًا للطباعة يحافظ على ترتيب الطرق والمصادر وصيغ الأداء والحواشي. الرسم نفسه يُنزّل كاملًا بدقة عالية عبر SVG أو PNG، وهما الأنسب للمشجّرات الواسعة.
