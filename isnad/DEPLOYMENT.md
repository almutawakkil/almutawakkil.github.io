# تعليمات النشر والاستبدال

التطبيق ساكن ومتوافق مع GitHub Pages كما هو، ومعدّ ليبقى تحت المسار الحالي `/isnad/`. لا تحتاج إلى npm أو خطوة build.

## استبدال النسخة القديمة

1. صدّر نسخة JSON احتياطية من المشاريع المهمة قبل التحديث.
2. احتفظ بعنوان GitHub Pages والمستودع الحاليين.
3. فك الحزمة، ثم استبدل محتويات مجلد الموقع المنشور باسم `isnad/` بملفات الحزمة: `index.html` و`styles.css` و`refinements.css` و`app.js` و`report.html` و`report.js` ومجلد `assets/` وملفات التوثيق. لا تنقل هذه الملفات إلى الصفحة الرئيسية للمستودع.
4. من Settings → Pages أبقِ إعداد النشر الحالي كما هو؛ المطلوب أن يظل عنوان التطبيق النهائي `https://almutawakkil.github.io/isnad/`.
5. ارفع التغييرات وانتظر اكتمال نشر GitHub Pages، ثم نفّذ تحديثًا كاملًا للصفحة لتجاوز الذاكرة المؤقتة.
6. لا تغيّر اسم النطاق أو مسار الموقع إذا أردت أن يبقى المتصفح قادرًا على رؤية IndexedDB القديم.

تُرحّل مشاريع الإصدار السابق عند فتحها إلى الإصدار 9، مع بقاء الأسانيد والمصادر والحواشي والمواضع والألوان وصيغ الأداء. الحقول الجديدة اختيارية، ولا يحوّل التطبيق التسميات القديمة المحتوية على أرقام إلى بيانات مصدر منظمة. يفضّل الاحتفاظ بنسخة JSON احتياطية قبل الاستبدال.

## المعاينة المحلية

شغّل أي خادم ملفات ساكن من هذا المجلد ثم افتح الصفحة. التخزين المحلي معزول لكل أصل؛ لذلك قد تظهر مشاريع مختلفة عند فتح الملف مباشرة، وعبر خادم محلي، وعبر GitHub Pages.
